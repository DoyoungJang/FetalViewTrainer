# Doppler educational material, v38

Added a separate Doppler section inside Measurement guidance for relevant views. This is indication-driven teaching, not a universal screening checklist or a diagnostic calculator. The current 3D plane is not automatically a Doppler acquisition plane; the text names additional planes explicitly.

## Clinical sources

- Bhide et al., ISUOG Doppler velocimetry guideline, 2021, DOI 10.1002/uog.23698. Verified original PDF captions, page layout and embedded image positions.
- ASE fetal echocardiography guideline, 2023: https://www.asecho.org/wp-content/uploads/2023/07/PIIS0894731723002067-1.pdf
- Fetal Heart Society, How to assess ventricular function by fetal echocardiography: expert guidance, 2026: https://pmc.ncbi.nlm.nih.gov/articles/PMC13325693/
- ISUOG 11–14-week scan, 2023, DOI 10.1002/uog.26106.

## Image provenance and panel audit

The original downloadable composites are retained. CSS clips only the relevant panel; each caption links to the complete source. No synthesized ultrasound or altered waveform is used. Exact gestational age is not inferred from appearance or selected trimester.
