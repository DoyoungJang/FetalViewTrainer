# FetalView

한국어 교육용 태아 초음파 표준 단면 아틀라스. `node server.mjs` 실행 후 http://127.0.0.1:4173 에서 사용합니다. 정적 배포 디렉터리는 `dist`입니다.

1분기 5개, 2분기 12개, 3분기 6개 모듈. Three.js 0.170.0 로컬 번들, 공개 CC BY 태아 GLB 모델, 기준 단면 2D 도식, 셀프 체크, 기기 내 학습 기록을 제공합니다. 글꼴만 Google Fonts에서 선택적으로 불러오며 연결 실패 시 시스템 글꼴을 사용합니다. 모델 파일은 사이트에 포함되어 외부 모델 서버 없이 로드됩니다.

## 교육 범위

ISUOG 2023 초기 검사, 2022 중기 검사, 2024 후기 검사와 AIUM 2024 표준 산과 검사 원문 링크를 앱 내에 제공합니다. 공식 학회 제품 또는 인증 교육이 아닙니다. 이 핵심 단면 모듈은 전체 검사 체크리스트가 아닙니다. 태아 수, 생존, 태위, 태반, 양수, 모체 구조 등은 별도 평가 대상입니다.

3D 외형은 gelmi.com.br의 예술적 모델이며 실제 환자 영상이나 해부학적으로 검증된 모델이 아닙니다. 모델 출처에 주수가 지정되어 있지 않으므로 분기 전환 시 외형을 임의로 변형·축소하지 않습니다. 내부 장기는 별도의 모식도이며 외형과의 위치 정합은 근사치입니다. 평면을 이동해도 오른쪽 기준 모식도는 그대로 유지됩니다. 실제 음향 영상 재구성, 진단, 위험도 계산, 도플러 또는 캘리퍼 실습은 제공하지 않습니다. 임상 교육 적용 전 전문가 검토가 필요합니다.

## 확인

`node --check dist/app.js`, `node --check dist/data.js`, `node tests.mjs`로 문법 및 모든 학습 항목의 상태 전환·퀴즈·로컬 기록·WebMCP 유효/잘못된 입력 처리를 확인합니다. 로컬 HTTP 응답 200 확인. 브라우저 시각 검증 및 실제 WebMCP 호스트 검증은 수행하지 않았습니다. WebGL 지원과 하드웨어 가속이 필요하며 지원되지 않는 경우 설명과 2D 학습을 유지합니다.

Three.js 라이선스: `dist/vendor/LICENSE.three`.

태아 모델: **Fetus** by **gelmi.com.br**, **CC BY 4.0**. 원본: https://sketchfab.com/3d-models/fetus-cdbadf8ba54e44ec9533a546dcd52830 . 상세 출처·배포 경로·인기 지표·변경 내역은 `dist/models/ATTRIBUTION.md`에 있습니다. 원본 GLB 형상은 유지하고 런타임에서 균일 스케일·위치·재질을 적용합니다. `node research/model-validation.mjs`는 실제 GLTFLoader로 파일을 로드하여 메시, 노멀, 폴리곤 수, 범위와 로컬 로딩을 확인합니다. `research/inspect_model.py`로 메시를 정면·측면·사선에서 렌더링해 형태를 확인했습니다. 브라우저 시각 검증은 별도입니다.

## 사선 단면과 심장 집중 보기

ISUOG 2023 심장 선별검사 pp. 792–793의 머리 방향 스윕·미세 기울임·회전 접근, ISUOG 2020 CNS Part 1의 소뇌 단면 후방 기울임, ASE 2023 태아 심초음파 지침을 추가 참고했습니다. 각 단면의 조작 설명과 직접 원문 링크를 화면에 제공합니다.

`dist/planes.js`는 법선 벡터와 기준점으로 평면을 정의합니다. LVOT/RVOT 시작 평면은 단순화한 모델의 해당 심실·혈관 기준점을 포함합니다. 수치 각도·좌표는 검증된 임상 프리셋이 아니며, 실제 태위·검사 접근과 일치한다는 의미가 아닙니다. 기본 평면 위 두 축을 회전한 다음 tilt/rock을 적용합니다. 회전만으로는 무한 평면의 방향이 변하지 않습니다. 슬라이더 이동은 회전 후 법선 방향을 따릅니다. 2D 기준 모식도는 고정 이미지이고 현재 단면에서 재구성한 초음파가 아닙니다.

심장 모듈에서 태아는 기본 5% 불투명도로 표시하며, 기타 장기는 숨깁니다. 심방·심실 네 개와 대혈관은 모식 구조이며 판막·벽 두께·혈류를 재현하지 않습니다. 구조 색은 산소포화도 또는 도플러 색상이 아닙니다. 노란 선은 실제 렌더링 메시와 평면의 삼각형 교차 계산 결과입니다. 심장만 표시, 전신 위치 보기, 확대, 윤곽 불투명도 조절을 제공합니다.

추가 검증: `node plane-tests.mjs`는 23개 항목의 회전·이동, 유출로 평면의 기준점 포함, 변환된 메시의 평면 교차, 심장 집중/단독 표시와 일반 보기 복원을 실제 Three.js 장면 객체에서 검사합니다. GPU·브라우저 시각 검증은 별도입니다.
