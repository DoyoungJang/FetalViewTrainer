# FetalView

한국어 교육용 태아 초음파 표준 단면 아틀라스. `node server.mjs` 실행 후 http://127.0.0.1:4173 에서 사용합니다. 정적 배포 디렉터리는 `dist`입니다.

1분기 5개, 2분기 12개, 3분기 6개 모듈. Three.js 0.170.0 로컬 번들, 절차적 3D 형태 모식도, 기준 단면 2D 도식, 셀프 체크, 기기 내 학습 기록을 제공합니다. 글꼴만 Google Fonts에서 선택적으로 불러오며 연결 실패 시 시스템 글꼴을 사용합니다.

## 교육 범위

ISUOG 2023 초기 검사, 2022 중기 검사, 2024 후기 검사와 AIUM 2024 표준 산과 검사 원문 링크를 앱 내에 제공합니다. 공식 학회 제품 또는 인증 교육이 아닙니다. 이 핵심 단면 모듈은 전체 검사 체크리스트가 아닙니다. 태아 수, 생존, 태위, 태반, 양수, 모체 구조 등은 별도 평가 대상입니다.

3D 형태는 단순화한 상대적 위치 설명용이며 실제 환자 영상이나 해부학적으로 검증된 모델이 아닙니다. 주수별 크기·기관 발달을 정량적으로 재현하지 않습니다. 평면을 이동해도 오른쪽 기준 모식도는 그대로 유지됩니다. 실제 음향 영상 재구성, 진단, 위험도 계산, 도플러 또는 캘리퍼 실습은 제공하지 않습니다. 임상 교육 적용 전 전문가 검토가 필요합니다.

## 확인

`node --check dist/app.js`, `node --check dist/data.js`, `node tests.mjs`로 문법 및 모든 학습 항목의 상태 전환·퀴즈·로컬 기록·WebMCP 유효/잘못된 입력 처리를 확인합니다. 로컬 HTTP 응답 200 확인. 브라우저 시각 검증 및 실제 WebMCP 호스트 검증은 수행하지 않았습니다. WebGL 지원과 하드웨어 가속이 필요하며 지원되지 않는 경우 설명과 2D 학습을 유지합니다.

Three.js 라이선스: `dist/vendor/LICENSE.three`.
